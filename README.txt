나의 메모보드 v2 - 사진 첨부 PWA

[핵심 기능]
- 제목 / 본문 / 자유 분류 / 태그
- 제목·본문·분류·태그 통합 검색
- 상단 고정 / 중요 메모 / 정렬
- 갤러리 사진 여러 장 첨부
- 사진 자동 축소·압축: 긴 변 최대 약 1600px, WebP/JPEG 품질 약 78%
- 목록용 썸네일 별도 저장
- 사진별 간단한 설명
- IndexedDB에 메모와 사진 분리 저장
- v1 localStorage 메모 자동 이전(같은 사이트 주소에서 실행한 경우)
- 텍스트 백업 / 사진 포함 전체 백업 / 복원
- PWA 홈 화면 설치 / 오프라인 앱 쉘 캐시

[휴대폰 테스트 권장 방법]
1. 이 폴더의 파일을 모두 GitHub 저장소에 업로드합니다.
2. GitHub Pages를 켭니다.
3. 생성된 https://...github.io/... 주소를 휴대폰 Chrome/Safari에서 엽니다.
4. 메모와 사진 첨부를 테스트합니다.
5. 브라우저 메뉴에서 '홈 화면에 추가'를 선택하면 앱처럼 실행할 수 있습니다.

중요: GitHub에는 프로그램 파일만 올라갑니다.
메모와 사진은 기본적으로 휴대폰 브라우저의 IndexedDB에 저장되어 GitHub 저장소로 전송되지 않습니다.

[왜 index.html 파일 직접 실행보다 GitHub Pages가 좋은가]
- HTTPS 환경이라 IndexedDB/PWA/서비스워커 동작이 안정적입니다.
- 같은 주소로 계속 접속할 수 있습니다.
- 새 버전을 GitHub에 덮어쓰면 휴대폰에서 같은 주소로 업데이트됩니다.
- 다른 기기에서도 프로그램 자체는 열 수 있습니다.
- 단, 개인 메모 데이터는 기기별로 따로 저장되며 자동 동기화되지 않습니다.

[백업 주의]
- '전체 백업' JSON은 사진을 Base64로 포함하므로 사진 수에 따라 파일이 커집니다.
- 평소에는 텍스트 백업을 자주 하고, 기기 변경 전에는 전체 백업을 권장합니다.
- 비밀번호, 금융 비밀번호, OTP/인증코드 등 고위험 비밀정보는 저장하지 않는 것을 권장합니다.
